A tiny program that votes with a single character. Run it and you get A -- coffee, no explanation, no punctuation, no newline. The whole argument is that coffee does not need one; the letter lands first and the reasoning arrives later, if at all. Tea can file its paperwork under B.

## Run it

```sh
python3 main.py
```
